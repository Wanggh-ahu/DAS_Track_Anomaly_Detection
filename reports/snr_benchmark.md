# 物理一致的缺陷注入 + SNR 扫描基准 + 共形校准

本文件记录本轮四项改造的实现、验证数据与结论。所有数字都来自本机实测，
运行环境 `D:\Apps\Anaconda\envs\das_env\python.exe`（Python 3.10 / torch 2.7.1+cu118）。

> **一句话结论**：把指标修干净之后，一个没有任何调参的 80–160 Hz 带通包络检测器
> （`bandpass`）在 **−5 dB 及以上的每一个 SNR，通道级定位都领先所有学习模型**
> （3 种子可复现），在过车级与 `ae_1d` 打平到 +10 dB。但**一旦缺陷频带在过车之间漂移
> ±70 %，固定带通掉 0.13、学习模型只掉 0.01，排序翻转**（见 §2 末尾）——固定频带的
> 红利来自"缺陷带与载荷带分离"，不是"调对了参数"。据此把输入从波形换成**对数幅度谱**
> （`stft_ae`，容量不变，只换表示）后，通道级 0.708 → 0.746、过车级 0.802 → 0.844，
> 标称形态下与匹配滤波打平，±70 % 抖动下**两项都第一且衰减最小**（§4）——这是本项目
> 第一个"换表示有效"的正结果。
> **但下面每一条都要按 §6 的五种子复核重新读一遍**：单次运行的 AUC 漂移有 ±0.04，
> 小于这个数的差值一律不算结论。按这条规则，jitter 0 的"`stft_ae` 胜带通"作废（实为
> 0.7439 对 0.7489，打平），jitter 0.7 的领先成立但方差大 6 倍（0.8294 ± 0.0334，
> 而非单种子的 0.8647 ± 0.0054）；"带通随抖动塌陷 0.14、AE 平坦"是**确认的**。
> **补齐全 SNR 扫描后优势也被框住**：通道级只在 +5 dB 打平，低 SNR 落后于 `ae_1d`，
> 高 SNR 落后于带通。单种子扫描里它过车级在 −15…−5 dB 领先，**3 个数据种子重跑后该领先
> 消失（假设作废）**；重跑反而暴露 `ae_1d` 在低 SNR 通道级最好、过车级却系统性低于随机
> （0.38–0.41）的反转现象（§4）。
> **而 §7 的对抗性检验把上面那个正结果又收窄了一圈**：换掉缺陷形态之后（扫频、周期冲击、
> 调幅共振），`stft_ae` 对固定带通**一次都没赢过**，`impulse_train` 上反而差 0.19；同时两个
> 自适应选带的经典对手（谱峭度、最响带）也都输给了"不动的频带"。所以准确的说法是：
> **它的优势属于那个缺陷家族，不属于"频域表示"本身**——逐 (通道, 频点) 标定买到的是
> 对同族频率漂移的鲁棒性，不是对形态变化的鲁棒性。
> 掩蔽自编码器（§5）的曲线始终是平的。另有一个方法论
> 副产物：活动窗标签会引入**车轴能量混淆**，必须用"窗内通道级"指标才测得准。
> 最后用一个双缺陷判别任务检验"频率选择性"本身：`stft_ae` 的二选一归因 **0.598**，
> 输给标定过的五带滤波器组 **0.640（Wilcoxon p = 0.009）**——**"残差峰值落在对的频点上"
> 不等于"模型会做频率判别"**。把滤波器组那套逐 (通道, 带) 标定搬到 AE 残差上（逐频点
> 中位数/MAD）后，判别裕度放大 5 倍、准确率仍停在 0.603 且落在重训噪声带内（0.564–0.598），
> **这个补救也被否掉**；它在过车级 AUC 上换来 +0.084（0.844 → 0.927），但暴露了共形阈值
> 在 n = 21 时的病根（阈值 = 样本最大值，**三分之一的情况下永不报警**），运行点塌成
> 不报警，故默认关闭。§3 给出了这个病根的定量证据与修法（过车级 α 改为 0.10）。

## 1. 缺陷物理模型：增益放大 → 瞬态冲击 / 局部共振

旧的 `anomaly_gain` 是对整条记录某一通道乘一个常数增益，这既不符合物理，
也无法控制信噪比。新的注入器在**背景合成完成之后**做加性叠加：

| 机理 | 波形 | 有效时长（实测） | 物理含义 |
|---|---|---|---|
| `impact` | 3 个 Gabor 载波（70 / 115 / 165 Hz），18 ms 冲击 + 10 ms 衰减 | 0.360 s | 车轮经过剥离/掉块时的宽带撞击 |
| `resonance` | 120 Hz 主频 + 1.45× 谐波（35 %），75 ms 衰减，截断于 6τ | 1.600 s | 车轴激励轨枕/扣件后的高频衰减振铃 |
| `mixed` | 两者叠加 | 1.600 s | 现场最常见的复合形态 |

每个缺陷由**每次车轴经过**独立激发（5 根轴 → 5 次激励），空间上沿通道方向
使用升余弦剖面（宽度 1–4 通道），因此缺陷不是"一条竖线"，而是一段有时序
结构的响应。

### SNR 的严格定义与校准

`SNR_db` 定义为缺陷支撑域上的功率比，且**在检测器输入处**度量，即经过
带通（5–200 Hz）+ 5 通道空间中值去除共模之后：

```
SNR = 10·log10( mean(|F(x + a)|²_support) / mean(|F(x)|²_support) )
```

其中 `F` 是真实预处理链。由于中值滤波是非线性的（`F(a+b) ≠ F(a)+F(b)`），
不能解析求解缩放系数，实现采用"线性初值 + 6 次定点迭代"直接对齐真实管线。

`scripts/verify_simulator.py` 独立复核（3 种机理 × 5 个 SNR，共 15 组）：

- **max |实测 − 目标| = 0.049 dB**
- `impact` 有效支撑 0.360 s，`resonance` / `mixed` 1.600 s
- 峰值通道 RMS 比：−15 dB 时 1.55 dB，+5 dB 时 21.55 dB

支撑域信息通过 `simulator.last_support_` 暴露，并被写成
`metadata.defect.{active_time_ranges_s, defect_channels, snr_db_processed, defect_scale}`，
供后续诊断脚本使用。

## 2. 自动化 SNR 扫描基准

`scripts/run_snr_sweep.py` + `configs/exp_snr_sweep.yaml`：

对每个 SNR 点自动完成 **改配置 → 重新生成合成数据 → 预处理 → 逐模型训练 → 评估 →
解析 `metrics_<model>.json` → 汇总 CSV/JSON → 绘图**。

- 数据集：60 条正常训练过车（其中 35 % 划为独立校准集）、48 条测试过车（正负各半）
- 每个 SNR 点使用**相同的随机种子**，因此曲线是配对的，差异只来自缺陷幅度
- 输出：`outputs/snr_sweep2/{summary.csv, summary.json, auc_vs_snr.png}`

### 指标：两个都不给"能量"留后门

窗口级 AUC 对这类缺陷有**天花板**：缺陷只在约 35 % 的时间窗内活跃，但同一条过车的
所有窗口都被标为正样本，即使完美检测器也只能到约 0.68。把标签换成"该窗口内缺陷是否
活跃"（`evaluation.window_labels: activity`）确实解开了天花板，却立刻引入了一个更隐蔽的
**标签混淆**：

> 缺陷由车轴激励，所以"活跃窗"正好就是"车轴经过窗"，而车轴经过使整窗宽带能量
> 高出约 12 %（同一过车内实测中位数差 +0.48，29 条过车）。于是任何能量敏感的打分器
> 都能在 −15 dB（缺陷比背景低 30 倍、根本不可见）拿到窗口 AUC 0.61——它检测的是
> 车轴，不是缺陷。

实测确认：−15 dB 下 `ae_1d` 的窗口 AUC 0.655，而把比较限制在**同一窗口内的通道之间**
后只有 0.49。因此基准改用两个都不可被能量"蹭分"的指标：

| 指标 | 定义 | 防住的作弊方式 |
|---|---|---|
| `channel_auc`（主） | 只统计活跃窗，在**同一窗口内**比较缺陷通道与健康通道 | 车轴经过的能量对所有通道是共模的，比较窗内通道即可消掉 |
| `profile_auc` | 先按通道在整条过车上做时间积分，再取最强 3 个通道 | 过车级标签只有正/负两类，两类都含车轴经过 |

### 主结论：匹配滤波（带通包络）是**形态固定时**最强的检测器

`bandpass` 只是"巴特沃斯带通 + 短帧包络 + 通道 z-score + top-3 均值"，**没有任何参数
在 SNR 上调整过**（带宽由缺陷物理固定）。它没有输给任何学习模型。

> 这个标题原来写的是"当前最强的检测器"，没有限定。§6 的五种子复核证明它**只在形态固定
> 时成立**：抖动 0.7 时带通通道级掉到 0.7098（自编码器 0.7343），过车级掉到 0.7418
> （0.8294）。限定语不是修辞，是结论的一部分。

单种子结果看起来很夸张（+5 dB：0.871 vs 0.806），但单种子的标准差就有这么大，
所以 **+5 / +10 dB 各补了 3 个独立数据种子**（`outputs/snr_seeds`，每点 3 × 48 条测试过车）：

| SNR | 模型 | `channel_auc` | `profile_auc` | 召回@共形阈值 | 实测误报 |
|---:|---|---:|---:|---:|---:|
| +5 | 带通 | **0.749 ± 0.002** | 0.882 ± 0.008 | 68.6 % | 3.4 % |
| +5 | 1-D AE | 0.716 ± 0.010 | 0.861 ± 0.035 | 63.9 % | 3.5 % |
| +5 | PCA | 0.707 ± 0.003 | 0.505 ± 0.040 | 4.6 % | 7.0 % |
| +5 | 掩蔽 AE | 0.696 ± 0.004 | 0.425 ± 0.048 | 3.5 % | 6.9 % |
| +10 | 带通 | **0.805 ± 0.002** | 0.967 ± 0.011 | 90.7 % | 3.4 % |
| +10 | 1-D AE | 0.761 ± 0.003 | **0.973 ± 0.002** | 94.1 % | 1.8 % |
| +10 | PCA | 0.765 ± 0.003 | 0.640 ± 0.038 | 20.8 % | 7.0 % |

修正后的结论，比单种子时更保守也更可靠：

- **通道级定位：带通在 −5 dB 及以上的每个 SNR 都领先，且方差极小**（+5：0.749 vs 0.716；
  +10：0.805 vs 0.761）。这个差距（0.03–0.04）远大于种子噪声（σ ≤ 0.01），是真实的。
  −15 / −10 dB 时各模型都在 0.49–0.60 之间（含 `ae_1d` 略高），属于随机水平，不作比较。
- **过车级 profile：+5 dB 打平**（0.882 vs 0.861，差距小于 1-D AE 的 σ = 0.035）；
  +10 dB 时 1-D AE 反超 0.006，同样**没有统计意义**。诚实的说法是
  "在 ≥ +5 dB 打平"，而不是"带通全面领先"。
- 单种子曾显示 +5 dB 领先 0.065，3 种子实际只有 0.021——**这正是 P0 要补多种子的原因**。
- 纯能量阈值在过车级从不构成有效检测器（≤ 0.56）；它在通道级能升到 0.79，只是因为
  那个指标容得下"哪条通道更响"，并不代表它能做过车级判决。
- 掩蔽 AE 的曲线几乎是平的（0.43–0.46），比 PCA 都差，Phase 4 的方向可以定论了。

**研究问题因此被重新定义**：要让一个学习模型值得存在，它必须打过
"0.88 @ +5 dB 过车级 / 0.75 @ +5 dB 通道级"这条线——目前没有任何模型做到。

### 共形阈值下的运行点（α = 0.05，过车级）

`profile_auc` 是无阈值的排序指标；部署看的是**在保证误报率 ≤ 5 % 时的召回**。
阈值由校准过车的分裂共形分位数给出，测试集不参与任何阈值选择。三种子的运行点列在
上文"主结论"表里（+5 dB：带通 68.6 % / 1-D AE 63.9 %；+10 dB：94.1 % / 90.7 %）。

两点实现细节值得记下：

- 21 条校准过车决定的分辨率就是 1/19 ≈ 5.3 %，所以"实测误报 3.4 %"已经是这个样本量
  能报出的量级；要把 α 压到 1 % 需要 ≥ 99 条校准过车。
- `ae_1d` 在 +5 dB 的实测误报只有 1.8–3.5 %，是因为它的校准分位数落在所有正常过车
  之上（保守）；带通则正好贴着名义值，说明它的分数分布更重尾。

### 低 SNR 段为什么全是 0.5

这不是脚本错误，已逐层验证：

- `diagnose_processed.py`：缺陷窗口覆盖率中位数 1.00，93 % 的过车 ≥ 0.75，
  峰值通道 RMS 比中位数 2.0 —— 缺陷确实落在保存下来的窗口里；
- 缺陷在 −5 dB 时幅度只有背景的 0.56 倍，而背景本身在车轴经过瞬间有 20 dB 以上的
  动态范围；注意 SNR 是**过车平均**意义下的局部 SNR，车轴经过瞬间的瞬时 SNR 还要再低
  约 20 dB；
- 带通之所以能在 −5 dB 首先抬头（0.543），是因为它把 65 Hz 的载荷主频挡在外面，
  只留下缺陷所在的 80–160 Hz；而 PCA 的残差对齐的是**全带宽方差**，被背景主导。

### 最关键的一问：固定频带的红利有多少来自"我的模拟器"？

上面的结论有一个致命的反驳：模拟器里缺陷的频带是固定的（共振 120 Hz + 1.45 倍谐波，
冲击载波 70/115/165 Hz），而 `bandpass` 恰好是 80–160 Hz。**这就是"用望远镜找已知的
那颗星"，赢了也不说明问题。**

所以给缺陷加了**逐过车的频率抖动** `simulation.defect_frequency_jitter`：每过车把所有
缺陷频率乘一个对数均匀分布的因子（`0.4` → 0.71–1.40 倍；`0.7` → 0.59–1.70 倍）。
`scripts/verify_simulator.py` 现在会检查这件事真的发生了：

```
defect peak: fixed 120-120 Hz, jittered 88-160 Hz     # 6 个种子
```

同时加了一个**多带滤波器组** `filterbank`（60–90 / 90–120 / 120–150 / 150–180 /
180–240 Hz，五个带各自做包络、逐 (通道, 带) 做 z-score 后跨带平均），代表"不学习、但
自适应"的经典做法。

+5 dB 下三种形态多样性条件的过车级 `profile_auc`：

| 频率抖动 | PCA | 带通 80–160（固定） | 滤波器组（5 带） | 1-D AE |
|---:|---:|---:|---:|---:|
| 0（标称形态） | 0.450 | **0.871** | 0.673 | 0.802 |
| 0.4（±40 %） | 0.463 | **0.848** | 0.648 | 0.770 |
| 0.7（±70 %） | 0.505 | 0.743 | 0.650 | **0.797** |

三个结论，一个比一个重要：

1. **固定带通对 ±40 % 的形态漂移几乎免疫**（0.871 → 0.848）。原因是它宽达 80 Hz
   （一个倍频程），而缺陷带离 65 Hz 载荷主频很远。**它赢不是因为它被精确匹配过，
   而是因为缺陷带与载荷带天然分离**——这比"调参调对了"强得多。
2. **朴素的"多带自适应"反而更差**（0.65–0.67，比单带掉 0.2）。控制组上的消融说明了
   原因：单带 120–150 Hz = 0.884，五带 `max` = 0.519，五带 `mean` = 0.661。
   盲组合五个带时，噪声带的方差会淹没信号带的增益——**没有先验就选不出带，
   多带覆盖的代价大于自适应的收益**。这一条把"加个滤波器组就行了"这条退路堵死了。
3. **抖动到 ±70 % 时排序翻转**：固定带通掉到 0.743，而 1-D AE 保持 0.797。
   3 个独立种子确认（带通 0.743 ± 0.003，1-D AE 0.797 ± 0.026；同一条件下两者
   在 jitter = 0 时是 0.882 ± 0.008 与 0.861 ± 0.035，即打平）。

也就是说：**学习模型的价值不在"更强的检测器"，而在"不需要事先知道缺陷频带"**。
这条结论同时解释了为什么之前所有架构改动都没用——它们都在改善"重建精度"，
而真正稀缺的是"频带选择能力"。

![形态多样性 vs 性能](outputs/morphology_vs_auc.png)

一个必须记下的细节：抖动 0.4 时 `profile_auc` 只掉了 0.02，但**共形阈值下的召回从
72.4 % 掉到 55.2 %**（带通），因为形态漂移伤害的是分布尾部（最弱的那几条过车），
而 AUC 对尾部不敏感。**只报 AUC 会低估形态多样性的伤害。**

### 这对下一步意味着什么

现在有三条硬约束，任何新模型都得同时满足：

| 约束 | 当时最好成绩 | 谁做到 |
|---|---|---|
| 不知道缺陷频带 | 0.797（1-D AE，jitter 0.7） | 只有 `ae_1d` |
| 单带级别的频带选择性 | 0.884（120–150 Hz 单带，jitter 0） | 只有"知道带"的方法 |
| 过车级时间积分 | 0.882（带通，jitter 0） | 带通与 `ae_1d` |

没有模型同时拿到两列。**P1 的目标因此非常具体：做一个在频率轴上做软选择、
而不是全局瓶颈压缩的自编码器**——即 STFT 对数幅度谱上的卷积 AE，让"哪个频带
不可解释"成为输出的一部分，而不是把整窗压成一个向量。§4 就是这件事的结果。

## 3. 独立校准集 + 共形预测 + 多区间定位

### 三方划分与分裂共形

`scripts/train.py` 现在按**过车（source）**划分：训练 / 校准 / 验证，互不重叠。
阈值不再是训练集分位数，而是分裂共形分位数：

```
k = ceil((n + 1)(1 − α)),  threshold = s_(k)
```

有限样本保证 `P(误报率 ≤ α) ≥ 1 − α`，但要求 `n ≥ ceil(1/α) − 1`。

实测（PCA，+15 dB 数据点）：

| 层级 | n_cal | α | 阈值 | 经验误报率 | 保证 |
|---|---:|---:|---:|---:|:--:|
| 窗口 | 982 | 0.05 | 13.22 | 4.89 % | ✅ |
| 过车 | 21 | 0.05 | 9.23 | 0.00 % | ✅ |

当 `n` 不足时（例如 α = 0.01 需要 99 条校准过车）自动退化为
`max × (1 + margin)` 并标记 `finite=false`，不会假装有保证。

### 多区间定位

`extract_anomaly_intervals` 现在可以返回多个区间，`interval_metrics_by_source`
采用**贪心 IoU 匹配**：

- 真值按连续通道段拆成多个区间（一条轨道可以同时有多处缺陷）
- 预测同样保留多个区间（默认最多 3 处）
- 未匹配的预测计为误报，未匹配的真值计为漏检
- 新增 `interval_precision / recall / F1`、`channel_precision`、`n_true_intervals` 等字段

CSV 现在写出 `predicted_intervals` / `true_intervals`（形如 `51-52;70-72`），
不再是单一区间。

### n = 21 时的过车级阈值：一个在三分之一情况下"永不报警"的估计器

窗口级的共形阈值是稳的：~1000 个标定窗，α = 0.05 时取的是从最大值数第 50 个序统计量。
**过车级没有这个余地。** 每份数据只有 60 条正常过车，`calibration_split=0.35` 给到 21 条，
而

```
k = ceil((21 + 1) × 0.95) = 21
```

也就是**第 21 个序统计量 = 样本最大值**。一个由单点定义的阈值没有任何稳定性可言，这正
解释了前几轮的现象：同一个模型同一份数据重训，过车级 FAR 一次 10.5 %、一次 5.3 %；
加了残差标定后变成 0 %，recall 归零。**那三个数都没算错，是估计器本身不稳。**

不猜，直接测。把 60 条正常过车的真实过车级分数做 300 次随机切分（21 条标定 / 39 条伪测试），
看每种估计器会给出什么 FAR：

| 数据集 | 模型 | 估计器 | 平均 FAR | FAR 标准差 | P(FAR = 0) | P(FAR > 2α) |
|---|---|---|---:|---:|---:|---:|
| j00 | STFT AE | 共形（现状） | 0.0454 | 0.0510 | **0.34** | 0.17 |
| j00 | STFT AE | GPD 尾部 | 0.0698 | 0.0552 | 0.12 | 0.27 |
| j00 | 带通 | 共形 | 0.0425 | 0.0508 | **0.38** | 0.13 |
| j00 | 带通 | GPD | 0.0511 | 0.0562 | 0.36 | 0.21 |
| j00 | 1-D AE | 共形 | 0.0406 | 0.0480 | **0.38** | 0.13 |
| j00 | 1-D AE | GPD | 0.0724 | 0.0534 | 0.04 | 0.29 |
| attr2 | STFT AE | 共形 | 0.0466 | 0.0522 | **0.34** | 0.20 |
| attr2 | STFT AE | GPD | 0.0658 | 0.0527 | 0.09 | 0.19 |
| attr2 | 带通 | 共形 | 0.0562 | 0.0648 | **0.31** | 0.22 |

**平均 FAR 一直是对的（0.041–0.056），标准差却和均值一样大。** 这就是共形保证的真实含义：
它是**对校准抽样取平均**的保证，不是"你抽到的这一份"的保证。在 5 个模型 × 2 个数据集上，
P(FAR = 0) 稳定在 **0.31–0.38**——大约每三次部署，就有一次得到一台永不报警的检测器，
而它的报告上写着"误报率 ≤ 5 %"。

试过用 GPD 尾部分布替代序统计量（`src/evaluation/tail_threshold.py`）：它对 AE 类分数确实
把 P(FAR = 0) 从 0.34 压到 0.12，但平均 FAR 偏高到 0.066–0.072，对带通则几乎没有改善。
**没有估计器能修好 n = 21**——尾部只有那么几个点，模型拟合只是在偏差和方差之间挪。

能做的是**要一个样本量撑得住的 α**。同一个 `stft_ae`、同一批分数：

| 过车级 α | 平均 FAR | FAR 标准差 | P(FAR = 0) | 测试集 recall（FAR） |
|---:|---:|---:|---:|---|
| 0.05 | 0.0454 | 0.0510 | 0.34 | 0.586（0.000） |
| 0.10 | 0.0901 | 0.0710 | 0.11 | **0.793（0.053）** |
| 0.20 | 0.1892 | 0.1029 | 0.00 | 0.793（0.158） |

α = 0.10 时检测器开始正常工作：不报警概率从 34 % 降到 11 %，测试集 recall 从 0.586 涨到
0.793 而实际 FAR 只有 5.3 %。想要 20 % 就过头了（实际 FAR 15.8 %）。

因此 `evaluation.pass_conformal_alpha` 现在是独立参数，**默认 0.10**，窗口级仍是 0.05。
控制数据上的实测：同一配置 recall 0.586 → **0.690**（FAR 0.000）。
下一节把"到底需要多少条标定过车"测成一条曲线，给出的规则是 **n_cal ≈ 5/α**。

一个必须并排写出的观察：这次重训的 profile AUC 是 0.900，上一次是 0.858——**AUC 自己也
有 ±0.04 的重训漂移**，和前面归因实验里看到的 0.564 / 0.598 是同一量级。所有单次运行的
AUC 差值小于 0.04 的表，都不该被当成结论。

### 标定要多少条过车：把"多攒数据"测成一条曲线

上一节说"唯一的办法是攒够正常过车"，但没说攒多少。共形公式只给出**有效性**的下限：
α = 0.05 时需要 n ≥ 1/α − 1 = 19 条。**有效性不等于可用性**——n = 21 时阈值确实是合法
共形分位数，只是它的实测误报会在 0 和 10 % 之间跳。

于是造了一份正常过车特别多的数据（`train_files: 400`，测试 120 条 → 75 异常 / 45 正常），
在同一批分数上把标定规模从 21 扫到 300，每个规模随机抽 200 次，看三件事：实测 FAR 的
散布、不报警的概率、以及**测试集运行点（召回）的散布**。

`bandpass`（确定性，无训练噪声）：

| 标定过车 | 平均 FAR | FAR 标准差 | P(FAR = 0) | 测试 FAR | 测试召回 |
|---:|---:|---:|---:|---:|---|
| 21 | 0.0439 | 0.0431 | 0.04 | 0.0301 | 0.669 ± **0.104** |
| 40 | 0.0464 | 0.0337 | 0.01 | 0.0299 | 0.699 ± 0.074 |
| 70 | 0.0453 | 0.0290 | 0.01 | 0.0260 | 0.701 ± 0.064 |
| 100 | 0.0493 | 0.0264 | 0.00 | 0.0294 | 0.720 ± 0.045 |
| 140 | 0.0513 | 0.0245 | 0.01 | 0.0290 | 0.726 ± 0.036 |
| 200 | 0.0477 | 0.0223 | 0.01 | 0.0256 | 0.725 ± 0.027 |
| 300 | 0.0512 | 0.0247 | 0.01 | 0.0234 | 0.734 ± 0.014 |

`stft_ae`：

| 标定过车 | 平均 FAR | FAR 标准差 | P(FAR = 0) | 测试 FAR | 测试召回 |
|---:|---:|---:|---:|---:|---|
| 21 | 0.0444 | 0.0398 | 0.06 | 0.0158 | 0.639 ± **0.092** |
| 40 | 0.0503 | 0.0384 | 0.01 | 0.0168 | 0.663 ± 0.071 |
| 70 | 0.0402 | 0.0284 | 0.01 | 0.0069 | 0.653 ± 0.055 |
| 100 | 0.0501 | 0.0268 | 0.00 | 0.0076 | 0.677 ± 0.037 |
| 140 | 0.0501 | 0.0222 | 0.01 | 0.0039 | 0.681 ± 0.028 |
| 200 | 0.0502 | 0.0232 | 0.01 | 0.0023 | 0.682 ± 0.023 |
| 300 | 0.0481 | 0.0221 | 0.00 | 0.0000 | 0.682 ± 0.014 |

三件事，两条结论：

1. **平均 FAR 从头到尾都在标称值上**（0.040–0.051）。这再次证明共形保证本身没坏——坏的
   是它在单次抽样上的可重复性。
2. **FAR 标准差降到一半就不再降**：0.043 → 0.025（bandpass）、0.040 → 0.022（stft_ae），
   拐点在 n ≈ 100–140，之后基本饱和。这正是序统计量从"最大值"变成"从最大值数第 5–7 个"
   的位置。
3. **真正被修好的是运行点**：同一份数据、同一份配置，标定 21 条时测试召回在 **±0.10** 上
   下摆（0.57–0.77），标定 140 条时只有 **±0.036**，300 条时 ±0.014。**这是工程上唯一
   在乎的量**——你不是在赌 AUC，你是在赌这批数据上召回是 57 % 还是 77 %。

由此得到一条可以直接写进配置的经验规则：

> **标定过车数应约为 5/α。** α = 0.05 时是 ~100 条，α = 0.10 时是 ~50 条。
> 共形公式给的 1/α − 1 = 19 条是**有效性**下限（保证成立），不是**可用性**下限
> （保证每次都能兑现）。

`scripts/train.py` 现在会在标定过车不足 5/α 时打警告，把这条规则变成运行时的可见提醒，
而不是留给读者从一张表里自己推。

**一个意外观察**：`stft_ae` 的测试 FAR 在标定 300 条时降到 **0.0000**，而召回保持在 0.682。
这不是过拟合阈值——是**训练池与测试池的分布差异**：标定池越大，阈值越接近训练池正常过车
的真实上界，而测试池的正常过车整体更低。也就是说这份数据上"误报预算"被当成了安全边际
花掉。它不影响可靠召回，但说明**跨池的 FAR 不能直接当成线上误报率**——真实部署里标定池
和目标池必须是同一个来源。

**还有一个必须并排写出的混杂**：这份数据集有 400 条正常过车，不只是标定变多，**模型本身
也用到了 6.7 倍的正常数据**。结果两个模型的成绩都涨了——`bandpass` 过车级 AUC 0.882
（60 条数据）→ **0.924**，`stft_ae` 0.853 → 0.896。所以"加数据"这件事同时修了两样东西：
标定稳定性，和基线自己的 z-score 标定质量。任何跨数据集规模的比较都要记住这一点，
不能把提升全记在阈值头上。

> 注意：§2、§4 里的 recall / FAR 都是在这套改动**之前**、过车级 α = 0.05 下跑出来的历史
> 数字。它们的 AUC 不受影响，但那些 recall 应当理解为"在 α = 0.05 这一次抽样下的运行点"，
> 而不是可复现的指标——上表说明它有三成概率落到 0。

## 4. 频率轴自编码器：把"缺陷在哪个频带"变成输出的一部分

### 为什么不是继续加模块

§2 的两组负结果指向同一件事：波形瓶颈（`ae_1d` 把 128 点压成 8 维向量）把频率信息
揉碎了，模型既学不到"缺陷在 120 Hz"，也无法表达"我解释不了这一段频率"。掩蔽 AE 的
失败是同一个病：它在补全空间上做文章，频率轴始终没有被显式表示。

`stft_ae` 因此只改一件事——**输入从波形换成对数幅度谱**，容量、逐通道结构、训练流程、
评分流程全部与 `ae_1d` 保持一致。两边之差就是"表示"本身的差。

STFT 用 64 点窗、8 点帧移 → 33 个频点（15.6 Hz）× 17 帧（8 ms），刚好能分开 65 Hz
载荷线、120 Hz 共振和 18 ms 的冲击。瓶颈 8×5×3 = 120 维，输入 33×17 = 561，压缩比
与 `ae_1d` 同级。

### 先写诊断，再跑分

掩蔽 AE 的教训是"损失降了但什么都没学到"。所以先做了 `scripts/diagnose_stft_ae.py`，
它回答三个问题，而且第一次运行就把一个真 bug 逼了出来：

1. **有没有在学？** 重建波形中位相关 0.991、幅度比 0.852 → 没有坍塌。
2. **有没有死频点？** 采集带内 0/12 个死点。
3. **残差是否选择在缺陷频率上？** 第一次跑出来是**否**：残差峰值落在 390–500 Hz，
   而预处理已经把信号限到 200 Hz 以内。原因是带外频点几乎没有信号，对数幅度谱的方差
   极小，标准化时被放大成了纯噪声。给每点尺度加上"不低于全带中位数 25 %"的下限之后，
   缺陷通道的残差峰值变成：

```
109.4 Hz / 125.0 Hz / 171.9 Hz / 187.5 Hz / 140.6 Hz
```

   正是 120 Hz 共振与 174 Hz 谐波（缺陷模型里 1.45 倍的那个分量）。**模型确实学到了
   缺陷的频谱位置**——这是波形瓶颈结构上做不到的。

频点定位精度：683 个异常窗里 54.0 % 的残差峰值落在真值 ±1 个频点内（15.6 Hz），
中位误差 1 个频点。

**在 ±70 % 形态抖动下这项能力不变**（54.2 %，中位误差仍是 1 个频点），而且残差峰值从
固定的 120 Hz 移到 140.6 / 171.9 / 187.5 / 125.0 Hz——**模型是跟着每条过车自己的缺陷
频率走的，不是一个伪装成网络的固定滤波器**。这是整轮里唯一一个能区分"学到频谱位置"
和"碰巧带了那个频带"的测量。

### 评分也必须搬进频域

如果仍用波形残差打分，频率轴会被平均掉。所以 `reconstruct` 主动抛
`NotImplementedError`，评分改在时频域：先对帧取平均（缺陷是持续事件，不是单帧尖峰），
再在 5–200 Hz 内跨三个相邻频点平滑后取最大值。

顺序是测出来的，不是猜的：先跨频取最大再平均帧，通道级 AUC 只有 **0.645**；先平均帧
再取最大是 **0.749**；平滑后再取最大是 **0.752**。**一帧里的一个噪声频点就能毁掉整个窗。**

### 结果

+5 dB，通道级 / 过车级 AUC（每格为对应条件下同一份数据）：

| 模型 | jitter 0 通道 | jitter 0 过车 | jitter 0.7 通道 | jitter 0.7 过车 |
|---|---:|---:|---:|---:|
| PCA | 0.703 | 0.450 | 0.703 | 0.505 |
| 带通 80–160（固定） | **0.746** | **0.871** | 0.710 | 0.743 |
| 滤波器组（五带） | 0.720 | 0.673 | 0.724 | 0.650 |
| 1-D AE | 0.708 | 0.802 | 0.706 | 0.797 |
| **STFT AE** | **0.746** | 0.844 | **0.738** | **0.865** |

（此表为最初的单种子 / 3 种子记录，**已被 §6 的五种子复核取代**，保留在此仅作对照，
看单次运行能偏多少。§6 的对应数字：jitter 0 带通 0.7489、`stft_ae` 0.7439；jitter 0.7
`stft_ae` 0.8294 ± 0.0334、带通 0.7418。）

三件事：

1. **同样的容量、只换表示**：通道级 0.708 → 0.746（+0.04），过车级 0.802 → 0.844
   （+0.04）。这是整个项目里第一个"换表示有效"的干净消融。五种子下 `stft_ae` 通道级
   0.7439 对 `ae_1d` 0.7104，**+0.033、5/5 同号，这条成立**。
2. **标称形态下与匹配滤波打平**（0.746 vs 0.746），过车级仍落后 0.027。五种子把这个
   "打平"确认得更死：0.7439 对 0.7489。
3. **±70 % 形态抖动下两项都第一**：五种子下通道级 +0.0245（5/5 同号）、过车级 +0.0876
   （5/5 同号）。**方向成立，但幅度比单种子看到的小**（过车级 0.088 而非 0.122）。

原 3 种子（jitter 0.7）：STFT AE 通道 **0.738 ± 0.002**、过车 **0.865 ± 0.005**。
五种子把过车级的散布从 ±0.005 修正到 **±0.033**——**那三个种子的"23σ"是巧合，真实
只有约 2σ。** 这一条是本次复核里最该记住的教训：种子数不够时，标准差会被严重低估，
而低估的标准差会让任何差值看起来都显著。

运行点：jitter 0 时旧记录显示 STFT AE 过车共形阈值在测试集上落到 10.5 % 误报
（其他模型 5.26 %），所以它的召回不能与带通直接比——AUC 可比，运行点不可比。§3 说明
这正是过车级阈值抽签的结果，现已把过车级 α 改为 0.10 并重跑（见 §6 运行点表）。


### 补全 7 点 SNR 扫描：优势的边界在哪里

上面所有结论只在 +5 dB 上验证过。把 `stft_ae` 补进完整的 −15…+15 dB 扫描（单种子）后，
它的优势被清楚地框住了——**而且框出了一个新的、方向相反的效应**。

通道级 AUC：

| SNR | PCA | 带通 | 1-D AE | STFT AE |
|---:|---:|---:|---:|---:|
| −15 | 0.514 | 0.490 | **0.581** | 0.523 |
| −10 | 0.532 | 0.534 | **0.598** | 0.545 |
| −5 | 0.572 | **0.607** | 0.626 | 0.594 |
| 0 | 0.634 | **0.681** | 0.659 | 0.670 |
| +5 | 0.703 | 0.746 | 0.697 | **0.750** |
| +10 | 0.761 | **0.802** | 0.742 | 0.785 |
| +15 | 0.804 | **0.840** | 0.795 | 0.820 |

过车级 `profile_auc`：

| SNR | PCA | 带通 | 1-D AE | STFT AE |
|---:|---:|---:|---:|---:|
| −15 | 0.414 | 0.483 | 0.376 | **0.550** |
| −10 | 0.443 | 0.501 | 0.416 | **0.541** |
| −5 | 0.448 | 0.543 | 0.417 | **0.597** |
| 0 | 0.432 | **0.688** | 0.617 | 0.601 |
| +5 | 0.450 | **0.871** | 0.806 | 0.866 |
| +10 | 0.586 | 0.955 | **0.973** | 0.926 |
| +15 | 0.755 | 0.996 | **1.000** | **1.000** |

两件事：

1. **通道级上，`stft_ae` 的优势不是普适的**：它在低 SNR 落后于 `ae_1d`，在 +10/+15 落后于
   带通，只在 +5 dB 与带通打平。**原先"带通在每个 SNR 都领先"的结论没有被推翻**，
   但"`stft_ae` 是更好的检测器"这句话只在 +5 dB 成立，必须限定条件。
2. **过车级上出现了一个反向效应**：在 −15 / −10 / −5 三个点，`stft_ae` 的 `profile_auc`
   都最高（0.550 / 0.541 / 0.597，第二名的带通是 0.483 / 0.501 / 0.543），而它的
   **通道级 AUC 同时低于 `ae_1d`**。`ae_1d` 恰好相反：通道级 0.581 最高，过车级 0.376
   （低于随机）。

解释：过车级分数是把通道分数沿时间积分后取 top-3。**通道级 AUC 高只说明"每个窗里排序
大概对"，不说明"同一个通道在每个窗里都排前面"**——`ae_1d` 每窗都对一点但位置漂移，
积分下来互相抵消；`stft_ae` 每窗略差但位置稳定，积分反而累积出信号。低 SNR 下真正
决定过车报警的是**通道排序的时间稳定性**，而这个量此前从未被单独测过。

**这个假设被三种子否掉了。** 上面 −15 / −10 dB 两行是单种子，用 3 个独立数据种子重跑后：

| SNR | 模型 | 通道级 | 过车级 |
|---:|---|---:|---:|
| −15 | STFT AE | 0.5281 ± 0.0039 | 0.5039 ± 0.0406 |
| −15 | 1-D AE | **0.5856 ± 0.0047** | 0.3831 ± 0.0273 |
| −15 | 带通 | 0.4961 ± 0.0054 | **0.5119 ± 0.0246** |
| −10 | STFT AE | 0.5493 ± 0.0018 | 0.5306 ± 0.0186 |
| −10 | 1-D AE | **0.6004 ± 0.0025** | 0.4047 ± 0.0323 |
| −10 | 带通 | 0.5401 ± 0.0054 | 0.5293 ± 0.0237 |

`stft_ae` 的过车级领先消失了：−15 dB 是 0.504 对 0.512，−10 dB 是 0.531 对 0.529，
都在一个标准差内。单种子的 0.550 vs 0.483 是**数据种子运气**（过车级单种子噪声本来就
有 ±0.04）。假设作废，我也不会保留它的解释。

**但重跑挖出一个更稳的现象**：`ae_1d` 在低 SNR 的通道级最好（0.586 / 0.600，σ≈0.005），
过车级却**系统性地低于随机**（0.383 / 0.405，6 个数据集上 σ≈0.03）。低于 0.5 不是"没有
信号"，而是**方向反了**：它给异常过车打的分数系统性低于正常过车。这个反转横跨两个
SNR、六个数据集、标准差很小，不可能是噪声。

成因尚未确认，暂不解释。可疑的方向有两个：低 SNR 下 AE 的残差被载荷/车轴结构主导，
而 `ae_1d` 的逐通道瓶颈恰好把这个结构压得最狠，于是"正常但载荷强"的过车残差更大；
也可能是 top-3 通道选择在低 SNR 下变成了选载荷最强的通道。**在弄清之前，低 SNR 的
过车级指标不能用 `ae_1d` 的通道级成绩去外推。**


### 频率归属：把"选择性"逼到必须现形（P1）

检出指标无法区分"学到了频谱位置"和"碰巧覆盖了那个频带"——宽带能量检测器两样都能做。
所以另立一个任务：**每条异常过车放两个缺陷站**，通道区间互不重叠、频率不同
（95 Hz 与 165 Hz），两站各自独立标定到同一个局部 SNR，**谁也不能靠更响被找到**。
检出因此在两个站上都成立，唯一能得分的方式是把**正确的频率安到正确的通道上**。

固定带通在这里没有输出可言（N/A）；**滤波器组有**——它每个带一个 z 分数——所以对手是
它，不是稻草人。判别指标是二选一强制选择：该通道在**自己站的频率**上的响应是否高于
**另一站的频率**，随机水平 0.500。统计单位是过车（同一条过车内的通道窗强相关），
28 条双站过车做配对检验。

| 模型 | 二选一归因准确率 | 每过车均值 | 中位判别裕度 | 峰值命中精确频点 |
|---|---:|---:|---:|---:|
| STFT AE | 0.598 | 0.608 ± 0.086 | +0.043 | 0.120 |
| 滤波器组（五带） | **0.640** | **0.650 ± 0.066** | +0.502 | 0.339 |

配对差 −0.041 ± 0.014，Wilcoxon **p = 0.009**。

**结论：假设被否掉。** 时频自编码器在单缺陷场景下确实把残差峰值放在缺陷频率上
（前文 54 % 落在 ±1 频点内），但一旦要求它**区分**两个同时存在的频率，它输给了一个
五行代码的滤波器组，而且差异显著。

这个否定比正结果更有信息量，因为它排掉了最诱人的解释：**"残差峰值落在对的频点上"
不等于"模型在做频率判别"**。峰值命中 12 % 说明它的频谱估计很散；而滤波器组每个
(通道, 带) 都对着正常数据标定过，二选一裕度是 AE 的 12 倍（0.502 对 0.043）。
换句话说，**标定过的粗频谱比未标定的细频谱更会判别**——这正好呼应 §2 里"盲组合五个带
更差"的反面：带少但标定好，反而赢。

两次修正记录（避免重复踩）：第一版把谐波比 0.35 留着，95 Hz 站的 1.45 倍谐波在
137.75 Hz、165 Hz 站的基频在 165 Hz，两站的谱线互相插进对方区间，判别被结构性混淆；
第二版把缺陷改成纯共振、谐波比为 0 才得到上表。第一版还错用了"命中精确频点"作指标
（33 个频点均匀猜是 3 %），那测的是定位精度而不是判别能力，已改为二选一强制选择。



### 把滤波器组的标定搬到残差上：排名变好，运行点变坏

归因输给滤波器组之后，最直接的猜想是：差距不在分辨率，而在**标定**。滤波器组每个
(通道, 带) 都对着正常过车归一化，AE 的残差则跨通道、跨频点都不可比。于是给
`STFTLogMagnitudeAE` 加了 `calibrate_normal()`：在**与训练不相交的标定切分**（982 个正常窗）
上算每个 (通道, 频点) 的残差中位数与 MAD，存成 buffer，打分时先标准化再做三频点平滑。

先看判别裕度：二选一归因的中位裕度从 **+0.043 提到 +0.208（5 倍）**——标定确实在做它
承诺的事。但准确率只从 0.598 动到 **0.603**，仍然输给滤波器组的 0.640，配对检验
**p = 0.002**。

| 模型 | 归因准确率 | 每过车 | 中位裕度 |
|---|---:|---:|---:|
| STFT AE（未标定，首测） | 0.598 | 0.608 ± 0.086 | +0.043 |
| STFT AE（未标定，重训） | 0.564 | 0.575 ± 0.093 | +0.018 |
| STFT AE（逐频点标定） | 0.603 | 0.614 ± 0.065 | **+0.208** |
| 滤波器组 | **0.640** | **0.650 ± 0.066** | +0.502 |

**结论：这个假设也被否掉。** 裕度涨了 5 倍，准确率却只从 0.564–0.598 挪到 0.603——
**落在重训噪声带内（同一个未标定配置重训两次就差 0.034）**，不能说标定带来了任何可证明
的判别增益。而滤波器组没有任何随机性（它不训练），0.640 是确定值，对两次未标定运行都
显著领先（重训那次配对差 −0.075 ± 0.015，**p < 0.001**）。

真正被证伪的是那个假设本身：**差距不在分数尺度的可比性**。裕度放大 5 倍而符号翻得一样
频繁，说明 AE 残差里两个频率的强弱对比太弱，放大它只是等比例放大噪声。标定不是缺失
的那一环。

标定在**排名**上倒是有真实收益（形态固定、SNR +5 dB 的对照数据）：

| 指标 | 未标定 | 逐频点标定 |
|---|---:|---:|
| 通道级 AUC | 0.7458 | 0.7437 |
| 过车级 AUC | 0.8439 | **0.9274** |
| 过车级 recall / FAR | 0.6207 / 0.1053 | 0.0000 / 0.0000 |

过车级 AUC +0.084 是这份报告里最大的单点提升，但**运行点塌了**：一个都不报。

要说清楚的是，这个对照每组只跑了一次，而同配置重训的不确定度不可忽略——把检查点恢复成
默认（未标定）重训一次，同一份数据给出的是：

| 运行 | 通道级 AUC | 过车级 AUC | recall / FAR |
|---|---:|---:|---:|
| 未标定 #1 | 0.7458 | 0.8439 | 0.6207 / 0.1053 |
| 未标定 #2（重训） | 0.7383 | 0.8584 | 0.5862 / 0.0526 |
| 标定 | 0.7437 | 0.9274 | 0.0000 / 0.0000 |

也就是说：**过车级 AUC 本身有 ±0.015 的漂移，FAR 能在 5.3 % 和 10.5 % 之间翻倍**。
+0.084 仍然大于这个漂移、方向也可信，但 recall 归零这一点在 `morph_j00` 和
`attribution2` 两个数据集上都复现了，不是单次抖动。

查下来不是标定算错，是**共形阈值在 n = 21 时的老问题**换了个方向发作：

| 量 | 值 |
|---|---:|
| 标定子集（21 条过车）的过车级阈值 | 2.370 |
| 全部 60 条正常训练过车的 q95 | 1.197 |
| 测试集最高过车级分数（异常） | 1.869 |

阈值取的是 21 条标定过车的**最大值**（α=0.05、n=21 时共形分位数就是样本极大值），而这
21 条恰好比整体偏难，于是阈值高过测试集所有分数。同一个机制之前让 FAR 冲到 10.5 %、
也在重训里让 FAR 落到 5.3 %，现在让它掉到 0——**方向不同，病因相同：过车级阈值只有
21 个样本可用。**

因此这个功能**实现保留、默认关闭**（`evaluation.residual_calibration`，缺省 `false`），
默认路径的可复现性不变。要打开它，得先把过车级阈值换成尾部稳定的估计（更多标定过车，
或用 EVT 拟合尾部分位数），而不是继续在 AUC 上做文章。**这也是下一轮真正该修的东西**：
它已经用三种不同方式（FAR 翻倍、recall 归零、重训漂移）三次干扰了结论，比继续加模型
重要得多。


### 这次真的说明了什么，以及没说明什么

**说明了**：之前所有"加模块"的尝试（记忆库、遮蔽、扩张卷积）都没用，不是容量不够，
而是**表示里没有频率轴**。频率轴一旦显式存在，同样的容量立刻开始工作（通道级
0.708 → 0.746）。这条消融是干净的：容量、逐通道结构、训练流程全不变，只换输入域。

**没说明，而且现在被否掉了**：频率选择性换来检测增益。两条证据合起来否定了它——
频域里 `max` 与 `mean` 打平（0.749 vs 0.752），说明检测增益来自"时频表示"本身；
而上节的二选一归因里，同一个模型**输给滤波器组 0.041（p = 0.009）**，说明它并没有在
做比别人更好的频率判别。**"残差峰值落在对的频点上"是一种描述，不是一种能力。**

真实的收益可以这样总结：换到对数幅度谱让模型学会了"这个窗里哪一段频率解释不了"，
这在**形态漂移**（±70 % 抖动）和**逐通道定位**上带来了稳健增益；但它并不构成一个
可用于**频谱判别**的估计器。后者也没能靠**逐 (通道, 频点) 标定**补上——标定把判别
裕度放大了 5 倍，准确率却仍在重训噪声内（0.564–0.603 对 0.640），所以缺的不是尺度
可比性，而是残差里那个频率对比本身太弱。

还有一个必须诚实标出的限制：**无监督在这份数据上并没有推翻经典匹配滤波**。带通在
形态固定时通道级 0.658、过车级 0.895，和 `stft_ae` 的 0.657 / 0.871 打平；它的弱点是
形态漂移（抖动 0.7 时过车级 0.743 对 0.865），而那正是它的固定频带被假设错了。目前
能站住的结论只有一条：**频域表示在形态不确定时更稳健**，不是"学出来的比设计出来的强"。

## 5. 掩蔽自编码器：三次迭代与一个负结果

按计划把 `spatial_masked_ae` 改为 60 % 遮蔽 + 记忆库 + 熵正则，并让推理时的遮蔽块
**比被评分的折更宽**（彻底切断边界泄漏）。结果发现三个真实缺陷，逐一修复：

1. **记忆库坍塌**：`z ← M(softmax(q·M))` 这种"替换式"寻址在训练中塌到单一槽位
   （实测熵 0.000 / 64 槽只用 1 个），解码器输出近似常数场（重建 std 0.013，
   输入 std 1.82，相关系数 −0.002），模型退化成能量检测器。
   → 改为**残差式记忆** `z ← z + M(w)`，熵权重 0.002 → 0.0005，温度 0.1 → 0.2。
2. **损失定义错误**：`_loss` 在整个场上求 MSE，网络只要复制可见通道、对遮蔽区
   输出常数就能把损失降到最低，于是"损失看着正常、模型完全没学"。
   → 改为**只在被遮蔽的位置**计算重建误差。
3. **感受野不足**：0.6 × 96 = 58 通道的连续空洞，超出浅层 U-Net 约 15 通道的
   感受野，网络根本看不到空洞两侧。→ 加入 dilation = 2 / 4 的上下文模块，
   把感受野扩到约 39 通道，并把遮蔽宽度降到 0.25。

修复后（+5 dB 同一条测试集）的消融：

| 版本 | 遮蔽比 | 记忆 | 损失域 | 扩张卷积 | profile_auc |
|---|---:|---|---|:--:|---:|
| v1 原始 | 0.60 | 替换式 | 全场 | ✗ | 0.412 |
| v2 | 0.40 | 残差式 | 全场 | ✗ | 0.430 |
| v4 | 0.25 | 残差式 | **仅遮蔽区** | ✓ | 0.436 |
| 带通基线 | — | — | — | — | **0.871** |
| 1-D AE | — | — | — | — | **0.806** |

**同一条数据上：带通匹配滤波 = 0.871，1-D AE = 0.806，PCA = 0.450，掩蔽 AE = 0.436。**

所以 Phase 4 的目标（低 SNR 下全面超过 PCA）**没有达成**，而且不是训练不充分：
修复后训练损失从 3.17 降到 2.76，确实在学，但"用邻道补一条 24–58 通道宽的连续
空洞"这个任务本身在 96 通道阵列 + 1.4k 训练窗口的规模下精度不够，重建误差
（约 93 % 的方差）淹没了缺陷本身（缺陷只占局部方差的 30 %）。此时空间遮蔽不仅
没有提供增益，还**主动删除了最有信息量的输入**：缺陷就藏在被遮蔽的带内。

诚实结论：对**加性、空间局域**的缺陷，空间遮蔽的自编码器存在结构性劣势；
全局瓶颈式自编码器（`ae_1d`）才是这一数据形态下的正确归纳偏置。掩蔽 + 记忆库
更适合"缺陷会污染周边上下文"的场景（例如耦合不良导致的整段异常），而不是
1–4 通道的点状缺陷。

## 6. 多种子复核：把小于 0.04 的差值全部作废

### 为什么必须做这一步

整份报告前半部分的每一个"A 比 B 强"，都来自**一次运行**。而重训研究给了个刺眼的数字：
同一份数据、同一份配置，重训一次过车级 AUC 从 0.844 到 0.858、再到 0.900；归因准确率
同配置两次是 0.598 和 0.564。**AUC 的单次运行漂移有 ±0.04。** 于是：

> 任何小于 0.04 的 AUC 差值，在这份报告里都不算结论。

这条规则砍掉了不少之前写下的句子，也保住了真正站得住的那几条。为了让它有牙齿，形态
抖动这条线重跑成 **jitter 0.0（5 种子）、0.4（3 种子）、0.7（5 种子）**，每点 5 个模型，
每个种子都是一份独立仿真的数据集。5 个种子是符号检验能到 p = 2⁻⁵ = 0.031 的最小数量，
3 个种子最低只能到 0.25——这也是 j40 不作为判决点、只作趋势点的原因。

注：§6 的 ± 一律是**样本标准差（n − 1）**，由逐种子指标文件算出；summary.csv 里
存的是总体标准差（n），所以同一格会差一点点（如带通 j00 通道级 0.0021 对 0.0019）。
报告里以本节为准。

一个让配对比较特别干净的性质：**正常过车不注入缺陷，所以同一 seed 下三个抖动臂的正常数据
逐位相同。** 这也解释了下面表格里 `pca` / `filterbank` / 带通的实测误报在 j00 和 j70 上
一模一样——那不是复制粘贴错误，是同一批正常过车。

从抖动 0 到 0.7 的落差，把"谁更强"讲清楚了：

| 模型 | 通道级 Δ | 过车级 Δ |
|---|---:|---:|
| 带通 | **−0.0391** | **−0.1405** |
| STFT AE | −0.0096 | −0.0233 |
| 1-D AE | +0.0073 | −0.0549 |
| 滤波器组 | −0.0014 | −0.0241 |
| PCA | −0.0048 | +0.0018 |

**带通输不是因为它退化得快，而是因为它一开始就把"缺陷在 80–160 Hz"当作已知条件**，
抖动 0.7 时缺陷频率可以落到 88–160 Hz 窗口之外，固定频带就不再匹配。自编码器不依赖这个
假设，所以曲线平——代价是假设成立时它也不占优。这正是"匹配滤波在失配时最脆弱"的直接
证据，而之前只有单种子的一行数字。

顺带纠正 §2 的主结论。当时写的是"匹配滤波是最强的检测器"，**只在形态固定时成立**。
正确的说法是：**形态固定时带通最强或打平，形态漂移时它最差；而"漂移"在真实轨道上是
常态，不是特例。**

## 7. 对抗性效度：我们的结论是不是模拟器设计出来的

前面六节的所有结论都建立在一个前提上——**缺陷形态是我们自己设计的**。`bandpass` 之所以在
固定形态下称王、在抖动下崩盘，某种程度上是构造使然：它把 80–160 Hz 写死，而缺陷频带就在
那里。要证明"学习一个频域表示有用"，必须排除两个替代解释：

1. **对手太弱**：一个会自己选带的经典方法就能做到同样的事，学习是多余的。
2. **缺陷太顺**：结论只在 Gabor 冲击和阻尼共振这两个家族里成立，换个形态就不成立。

本节分别打这两枪。两枪都用了和前面相同的纪律：同 seed 配对、多种子、符号检验，并且只把
效应量大于噪声 3 倍的差值当结论。

### 7.1 第一枪：谱峭度（kurtogram）—— 自适应选带的经典答案

工业界检测轴承和齿轮故障的标准做法是**谱峭度**：不预设频带，而是在数据上算各频带的峭度，
挑最"冲击"的那条带，再做包络分析。它不需要训练、不需要缺陷知识，却**自己会找频带**。
如果它能追平 `stft_ae`，那"学习"就只是"选带"的昂贵替身。

实现见 `src/models/kurtogram.py`：13 个重叠带（31.25 Hz 与 62.5 Hz 两个二分族，半宽跳步，
覆盖 30–200 Hz），选择准则是**包络的超额峭度**，判决量是选中带的**包络对数能量**，两者都
按 (通道, 带) 在正常窗上做中位数/MAD 标定（和滤波器组同等待遇，否则 argmax 只会挑样本数
最少的带）。

第一个发现是：**它输得很惨。**

| 抖动 | 模型 | 通道级 | 过车级 |
|---|---|---:|---:|
| 0.0 | 带通 | 0.7489 | 0.8823 |
| 0.0 | **kurtogram** | **0.6744** | **0.5745** |
| 0.0 | STFT AE | 0.7439 | 0.8527 |
| 0.7 | 带通 | 0.7098 | 0.7418 |
| 0.7 | **kurtogram** | **0.6640** | **0.5652** |
| 0.7 | STFT AE | 0.7343 | 0.8294 |

在三个抖动下，kurtogram 的过车级 AUC 是 0.57 / 0.56 / 0.57——**贴着随机线**，比它想取代的
固定带通低 0.18–0.31。

但这个结果**不能直接读成"自适应选带没用"**，因为峭度选错了准则：峭度是为**冲击型**故障
（轴承剥落）设计的，而这里的缺陷是**单音共振**，本来就不冲击。峭度挑中的是背景里最"尖"
的带，不是缺陷所在的带。用错误的准则去否定自适应，是无效的驳论。

### 7.2 用对了准则仍然输：逐窗"最响的带"

于是补一个准则正确的版本（`LoudestBandBaseline`）：同样的 13 个带、同样的标定，但**选
标定后包络能量最大的带**——针对单音缺陷，这才是自然的经典做法。这是能区分两种解释的
关键对照：

- 若它追平或超过 `stft_ae` → 结论应改写成"**选带**有用，学习是多余的"；
- 若它仍然输 → 说明瓶颈不在"选不选带"，而在别处。

| 抖动 | 带通（固定） | 滤波器组（盲组合） | 最响带（自适应） | kurtogram（峭度） | STFT AE |
|---|---:|---:|---:|---:|---:|
| 通道 0.0 | **0.7489** | 0.7255 | 0.6895 | 0.6744 | 0.7439 |
| 通道 0.4 | **0.7409** | 0.7258 | 0.6880 | 0.6579 | 0.7293 |
| 通道 0.7 | 0.7098 | 0.7241 | 0.6918 | 0.6640 | **0.7343** |
| 过车 0.0 | **0.8823** | 0.6680 | 0.5434 | 0.5745 | 0.8527 |
| 过车 0.4 | **0.8507** | 0.6595 | 0.5583 | 0.5557 | 0.8623 |
| 过车 0.7 | 0.7418 | 0.6439 | 0.5748 | 0.5652 | **0.8294** |

配对结果（j70，5 种子，全部 5/5 同号）：

- `stft_ae − 最响带`：通道 **+0.0414**，过车 **+0.2546 ± 0.0229**
- `最响带 − 带通`：通道 **−0.0594**，过车 **−0.1670 ± 0.0353**
- `最响带 − 滤波器组`：通道 −0.0360，过车 −0.1246

**两个自适应选择器都比固定带通差 0.06（通道级）到 0.17–0.34（过车级）。** 这排除了
"对手太弱"的解释，但方式和我们预想的不同：不是学习赢了自适应，而是**两种自适应都输给了
一个不动的频带**。

### 7.3 为什么会这样：自适应选错了时间尺度

机制不复杂，而且能解释全部三行数字。缺陷频带在**一条过车之内是恒定的**，只在**过车之间**
漂移。而这两个选择器都是**逐窗**选带：每个窗口各自 argmax，选中的带随之乱跳。

于是过车级的统计量（对窗取平均）变成了"逐窗最大值"的平均——它的方差由每个窗口里偶然最响
的那条带决定，而不是由缺陷所在的那条带决定。缺陷信号本来是**在整条过车上都一致地出现在
一个带里**的，逐窗选择恰好把这个一致性毁掉了。

滤波器组（盲平均）至少不会引入这个额外的方差，所以它是 0.64–0.67 而不是 0.54–0.57；
固定带通把正确性直接写死，所以是 0.74–0.88。

这反而把 `stft_ae` 的优势解释得更准确了：它不是在"选带"，它是**在整条过车上对完整频率剖面
做池化**（逐 (通道, 频点) 标定后按帧平均，再在频带上取聚合）。它用对了时间尺度——先沿时间
积分，再在频率上决策。**学习带来的不是"自适应"，是"在对的时间尺度上做聚合"。**

⚠️ **本节留下的缺口（已在 §7.7 补测并证伪）**：逐**过车**选带（用整条过车的统计量选一次带，
再算能量）才是这个机制推导出的最优经典方案，而它当时没有被测试。§7.7 把它连同"用标签选带的
oracle 上界"一起做了——**结论是选带在任何时间尺度上都不成立，连作弊都不行**。本节关于
"学习买到的是对的时间尺度"的解释因此需要再收一层：真正的分界不是"选带的时间尺度"，
而是"**做选择还是做平均**"。

### 7.4 第二枪：换成不是我们设计的缺陷形态

谱峭度那组只证明了"对手不会自己选带"。更根本的问题是：**如果缺陷根本不是我们设计的那两个
家族呢？** 为此在模拟器里加了四种刻意放在家族外的形态（`simulation.anomaly_type`）：

| 形态 | 物理对应 | 为什么它在家族外 |
|---|---|---|
| `click` | 2.2 ms 宽带冲击 | 太短，装不下三个载波 |
| `chirp` | 50 ms 内 0.55f → 1.6f 线性扫频 | 能量在频率上**移动**，不是停在一个带里 |
| `impulse_train` | 9 Hz 周期冲击串 | 不是"每次轴通过响一次"，而是**周期性重复**，包络带线谱（轮扁/波磨） |
| `am_resonance` | 120 Hz 载波被 22 Hz 调幅 | 谐波模型只有一根线，它有一对边带 |

四种形态都走同一套 SNR 标定（局部 +5 dB，预处理后实测），所以"难不难"是可控的，变的只是
**形态**。跑 3 个数据种子 × 3 个模型（`bandpass` / `bandselect` / `stft_ae`）。

| 形态 | 模型 | 通道级 | 过车级 profile | 过车级窗口均值 |
|---|---|---:|---:|---:|
| `click` | 带通 | 0.525 | 0.525 | 0.497 |
| `click` | 最响带 | 0.501 | 0.477 | 0.476 |
| `click` | STFT AE | 0.503 | **0.548** | **0.541** |
| `chirp` | 带通 | **0.583** | **0.647** | **0.829** |
| `chirp` | 最响带 | 0.535 | 0.483 | 0.531 |
| `chirp` | STFT AE | 0.540 | 0.556 | 0.595 |
| `impulse_train` | 带通 | **0.681** | **0.857** | **0.835** |
| `impulse_train` | 最响带 | 0.645 | 0.582 | 0.490 |
| `impulse_train` | STFT AE | 0.603 | 0.669 | 0.625 |
| `am_resonance` | 带通 | **0.642** | **0.828** | **0.928** |
| `am_resonance` | 最响带 | 0.588 | 0.549 | 0.576 |
| `am_resonance` | STFT AE | 0.605 | 0.746 | 0.790 |

配对差（同 seed 相减，`stft_ae − 带通`，3 种子）：

| 形态 | 过车级 profile | 种子一致 | 通道级 | 种子一致 |
|---|---:|---:|---:|---:|
| `click` | +0.023 ± 0.058 | 2/3 | −0.022 ± 0.004 | 0/3 |
| `chirp` | −0.091 ± 0.111 | 1/3 | **−0.043 ± 0.002** | **0/3** |
| `impulse_train` | **−0.188 ± 0.039** | **0/3** | −0.078 ± 0.003 | 0/3 |
| `am_resonance` | −0.081 ± 0.064 | 0/3 | −0.037 ± 0.002 | 0/3 |

**结论很硬：离开原来的缺陷家族，`stft_ae` 一次都没有赢过固定带通。**

- `impulse_train` 上差距 0.19、三个种子全部同号、散布只有 0.039——**这是本节最强的一条**。
- `chirp` 上 profile 差为负但散布大（0.111），按本报告的规矩只能算方向；不过通道级差
  −0.043、散布 0.002，是干净的。
- `am_resonance` 上 −0.081 但散布 0.064，同样只能算方向；通道级 −0.037 刚好在这条
  0.04 规矩的边界上，**不算结论**。
- `click` 上三个模型全在随机线（0.48–0.55）：2 ms 宽带脉冲在 +5 dB 下的**每带 SNR** 极低，
  谁都没有信号。这不是谁赢的问题，是两类方法都没戏。

### 7.5 这次失败说明了什么：优势属于家族，不属于表示

把家族内和家族外的过车级 profile 放在一起看，`stft_ae` 相对带通的差值是：

| 条件 | `stft_ae − 带通`（过车级 profile） |
|---|---:|
| 家族内，抖动 0.0 | −0.030（打平） |
| **家族内，抖动 0.7** | **+0.088（5/5 同号）** |
| 家族外 `click` | +0.023（都在随机线） |
| 家族外 `chirp` | −0.091 |
| 家族外 `impulse_train` | **−0.188** |
| 家族外 `am_resonance` | −0.081 |

**它只在"抖动 0.7、且缺陷是阻尼单音"这一个格子里赢。** 这个格子恰好是逐 (通道, 频点)
标定最擅长的地方：缺陷在一条过车之内频率恒定，在过车之间漂移——所以"这一条过车的频谱
形状和正常谱差多少"是个干净的问题，而按频点标定正好把这问题归一化了。

一旦形态换成扫频、周期冲击、调幅，这条推理就失效：

- **`chirp`**：能量在 50 ms 内从 60 Hz 扫到 180 Hz，固定 80–160 Hz 频带**几乎全程匹配**；
  而逐频点标定被"每个频点只在一小段时间里有能量"稀释了。
- **`impulse_train`**：冲击是窄带的、且**周期重复**，带通的短帧包络直接把这个周期性抓住了；
  AE 的频率剖面把它平均掉了。
- **`am_resonance`**：载波在带内，AE 的剖面把边带抹平。

所以正确的结论不是"频域表示没用"，而是：

> **"换表示有效"这个结论的适用范围是它被测的那个家族。** 逐 (通道, 频点) 标定买到的
> 是"对同一形态的频率漂移的鲁棒性"，不是"对形态变化的鲁棒性"。这两件事在报告前半部分
> 被混为一谈了，本节把它们分开。

这条也反过来给前面的正面结果划了边界：§4/§6 里 `stft_ae` 在抖动下的优势是真的（5/5 同号、
效应量 8 倍于噪声），但**它不能外推成"学习到了频域表示所以更鲁棒"**。同样能解释它的还有
一个更朴素的说法——"缺陷形态在这个家族里是**单音**，而单音的逐频点标定天然稳定"。

⚠️ **本节的自查**：`chirp` 的频段 60–180 Hz 与带通的 80–160 Hz 高度重叠，所以它对带通而言
并不算"失配"。要真正检验带通在扫频下的脆弱性，应该跑一个**扫出通带**的变体（如 20→90 Hz）。
这一条没做，是本节的方法学缺口，也是下一步最该补的实验之一。

### 7.6 第三枪：把"时间尺度"这个解释也拿去证伪

§7.4 的结论是"`stft_ae` 的优势属于家族"。但这句话有个更诱人的读法：

> 它输在扫频和周期冲击上，是因为它把整条过车的频谱**平均**了；只要换成会看
> **时变结构**的表示，就该把分拿回来。

这个读法能解释全部已有结果，也直接给出了下一步该建什么模型。所以在动任何网络之前，
先用两个**不用训练**的检测器把它证伪掉（`src/models/timescale.py`）：

| 检测器 | 看什么 | 按理该赢在哪 |
|---|---|---|
| `envspec` 包络谱 | 带通 → Hilbert 包络 → 对**包络**做频谱，取 3–45 Hz 调制能量 | `impulse_train`：9 Hz 周期冲击应在包络谱上留线谱 |
| `tftraj` 时频轨迹 | 逐帧谱质心拟合直线，取 `\|斜率\| × R²` | `chirp`：扫频应给出大而连贯的斜率 |

两者都按同样的规矩标定（逐通道中位数/MAD，只用正常窗）。结果：

| 数据 | 带通 profile | `stft_ae` profile | `envspec` | `tftraj` |
|---|---:|---:|---:|---:|
| `impulse_train` | **0.857** | 0.669 | 0.547 | 0.489 |
| `chirp` | **0.647** | 0.556 | 0.443 | 0.466 |
| `am_resonance` | **0.828** | 0.746 | 0.445 | 0.487 |
| `click` | 0.525 | 0.548 | 0.443 | 0.474 |
| 族内 抖动 0.0 | **0.882** | 0.853 | 0.436 | 0.499 |
| 族内 抖动 0.7 | 0.742 | **0.829** | 0.447 | 0.522 |

**两个检测器在所有格子里都在随机线附近或以下，在它们最该赢的两个格子里也没赢。**

而且它们不是"没信号"，是**系统性低于 0.5**（0.436–0.522）。这意味着注入缺陷
实际上**降低了**包络调制量：缺陷给的是窄带稳态能量，它抬高了包络的均值，反而把
原本由车轴周期性带来的调制**摊平**了。检测器的方向是反的。

所以"时间尺度"这个解释作为**机理描述**仍然成立（它确实说明了为什么逐窗选带和
帧平均会失效），但它作为**改进路线**是空的——知道该在哪个尺度上积分，并不等于
存在一个在那个尺度上更好用的统计量。

这一步的价值在于：它用**几小时**的确定性实验，替代了一个**几周**的建模周期，
并且把结论从"我们没试过"变成"我们试过，不行"。负结果写到这个程度才算闭环。

⚠️ 这一节同时排除了一类"补一个模块就行"的审稿意见：加包络解调、加时频轨迹特征，
都不会改变排序。

### 7.7 第四枪：逐过车选带，连同"作弊上界"

§7.3 的解释是"逐窗选带的时间尺度错了"，由此推出一条当时没测的预测：

> 缺陷带在一条过车之内恒定、在过车之间漂移，那么**每条过车选一次带**就应该把分拿回来。

这条预测现在被测了（`scripts/evaluate_pass_band.py`），并且配了三个让结论能成立的对照：

| 变体 | 规则 |
|---|---|
| `bands_mean` | 跨带**取平均**（`filterbank` 的原做法），在 5 个带、96 个通道上铺开 |
| `bands_max` | 跨带取最大 |
| `fixed_best_pooled` | 在测试集上择一固定带（对测试集有轻度依赖，只作参照） |
| `per_pass_raw` | 逐过车选 z 最大的带，**不校正选择偏置** |
| `per_pass_cal` | 逐过车选带，选择统计量先对**训练集**（全正常）的零分布标准化 |
| `per_pass_channel_cal` | 逐 (过车, 通道) 选带，同样标准化 |
| `per_pass_oracle` | **作弊**：用标签选带（缺陷过车选最分离的带，正常过车选最低的带） |

**先把脚本口径对齐**：`bands_mean` 在抖动 0.7 上得到 **0.695 ± 0.008**，
`evaluate.py` 存下的 `filterbank` 过车级是 **0.6931**——复现，可以比。

| 变体 | 抖动 0.0（5 种子） | 抖动 0.4（3 种子） | 抖动 0.7（5 种子） |
|---|---:|---:|---:|
| `bands_mean`（取平均） | **0.714** | **0.717** | **0.695** |
| `bands_max` | 0.528 | 0.599 | 0.619 |
| `fixed_best_pooled`（择一固定带） | 0.467 | 0.475 | 0.477 |
| `per_pass_raw`（裸选） | 0.329 | 0.261 | 0.370 |
| `per_pass_cal`（校正选） | 0.414 | 0.549 | 0.541 |
| `per_pass_channel_cal` | 0.502 | 0.564 | 0.585 |
| **`per_pass_oracle`（用标签作弊）** | 0.484 | 0.575 | 0.581 |

**三件事同时被这条表否定掉了。**

1. **逐过车选带不成立**，而且不是"差一点"：最好的无标签变体（逐通道校正选带）
   比取平均低 0.11–0.21。
2. **连作弊都不成立**：`per_pass_oracle` 用标签替每条过车挑出最好的带，
   仍然比"把所有带平均起来"低 **0.11–0.23**（0.581 对 0.695）。
   这是本节最强的一条——它说明失败的原因不是"选得不准"，而是**"选"这个动作本身在丢信息**。
3. **裸选带会掉到随机线以下**（0.261–0.370）。在 5 个带 × 96 个通道上取最大，
   正常过车也会被抬高，选择偏置让两类过车的分数都上移、排序被打乱。
   这是一个很容易把人骗过去的陷阱：如果只看某个单一指标，会以为逐过车选带"有效"。

**机制**：冲击型缺陷的能量并不落在一个带里——三个载波（70/115/165 Hz）加上衰减的边带，
本来就横跨 2–3 个带。取平均保留了全部证据；选一个带等于主动丢掉 4/5 的观测，
同时把"选哪个"的噪声也加进来。所以正确的说法不是"选带的时间尺度要对"，而是

> **在这个任务上，"做平均"严格优于"做选择"，与选择发生在哪个尺度无关。**

**为什么选带会输：信号没少，方差多了。** 把两种归约的过车分数摊开看
（抖动 0.7，seed_0，48 条过车 / 29 条缺陷）：

| 归约方式 | AUC | d′ | 过车分数 sd | 均值差 Δ |
|---|---:|---:|---:|---:|
| **跨带取平均** | **0.704** | **0.87** | **0.10** | 0.08 |
| 跨带取最大 | 0.632 | 0.46 | 0.19 | 0.08 |
| 逐过车选带（校正） | 0.666 | 0.19 | 0.61 | 0.12 |
| 逐过车选带（作弊） | 0.657 | 0.41 | 0.57 | **0.22** |

平均与取最大的**均值差完全相同（0.08）**，但取最大的标准差是两倍。作弊版把均值差
推到 0.22（说明选对带确实提高信号），方差却涨到 0.57，d′ = Δ/sd 仍只有 0.41。
所以选带的问题不是选不准，是**每选一次就引入一次随机尺度**：一条过车里哪个带最大，
取决于缺陷能量与该带本底噪声的相对位置，而这个位置在过车之间变化。

这把 §7.3 的解释又推进了一层：`stft_ae` 之所以赢，不是因为它"在对的时间尺度上选",
而是因为它**把整条过车的频率剖面池化起来**——它也是在平均，只不过平均得更有结构。

⚠️ **本节的边界**：带集是 `filterbank` 的 5 个带（60–240 Hz，30 Hz 步长），
所以"更细的带（谱峭度的 13 带）"没有被覆盖；选带是逐过车的，没有试"逐过车 + 按通道分组"。
族外（`oof_*`）那四组没有训 `filterbank`，因此本节不含族外数据。
这三点都不影响"平均优于选择"这一条，因为 oracle 已经把这个方向的上界压在了 0.58 以下。

### 7.8 四枪打完，剩下的是什么

把 §7.3–§7.7 连起来看，被排除的改进路线是：

| 尝试 | 结果 |
|---|---|
| 逐窗自适应选带（谱峭度 / 最响带） | 输给固定带通 0.17–0.32 |
| 换学习表示（STFT 对数幅度谱） | 只在同族抖动下赢，换形态即失效 |
| 会看时变结构的检测器（包络谱 / 时频轨迹） | 0.44–0.55，系统性低于随机 |
| 逐过车选带（含作弊上界） | 最好的无标签变体 0.58，作弊 0.58，取平均 0.70 |

四条路线、四个独立实验，指向同一个结论：**在这个任务上，"怎么聚合"比"用什么表示"重要，
而聚合的最佳形式是平均，不是选择。**

这既是负结果，也是一条可用的工程判据：拿到真实数据后，第一件事应该是**先做跨带平均的
匹配滤波基线**，而不是先上网络；只有当某个形态明确要求"不该平均"时（例如缺陷只占一个
极窄带、而本底是宽带的），才值得引入选择机制——而我们至今没有一个这样的形态。
