# 学位论文骨架：聚合与选择

> 面向 DAS 轨道结构异常检测的**聚合尺度判据**

本文档不是论文正文，是把已有的四组实验组织成一条论证线的工作稿。每一节都标注了
证据来源（报告章节 / 产物文件），凡是还没有证据的地方一律标 **【待补】**，
不许在写正文时被顺手写成结论。

## 0. 一句话主张与摘要草稿

**主张**：在移动载荷强非平稳本底下，轨道结构异常的可检测性主要由**证据如何聚合**
决定——沿频率、时间、样本三个轴上的归约方式，比"表示是学的还是手工的"更能解释
性能差异；而在小效应量条件下，**平均严格优于选择**。

**摘要草稿**（约 300 字，可直接改）：

> 分布式声学传感为长距离轨道监测提供了连续观测手段，但其本底由列车移动载荷主导，
> 且真实病害样本稀缺，因此无监督检测成为主流思路。本文不复述"构造更强网络"的路线，
> 而是追问一个更基础的问题：在什么条件下，哪种检测范式成立。为此建立了一个可控基准：
> 加性物理注入并定点标定局部信噪比（精度 0.049 dB），隔离窗内通道级与过车级指标，
> 以多种子配对检验取代单次运行，并以独立标定集上的共形分位数给出可复现的运行点。
> 在此基准上比较了匹配滤波、盲滤波器组、三类自适应选带、一维与时空自编码器、
> 以及 STFT 对数幅度谱自编码器。结果显示：（1）零参数的跨带平均匹配滤波在绝大多数
> 条件下不劣于任何学习模型；（2）三类自适应选带全部劣于跨带平均，即使用标签选择
> 频带的上界也无法超越；（3）学习表示的唯一优势出现在"缺陷为窄带稳态、且频带在过车
> 之间漂移"的条件下，换为扫频、周期冲击或调幅形态后优势消失；（4）共形运行点的稳定性
> 由标定样本量决定，实测需 n_cal ≈ 5/α。据此给出聚合判据：
> 取最大不增加信号、只增加方差——两种归约的均值差相同（0.08），而选带的过车分数
> 标准差翻倍（0.19 对 0.10）；只有当单带效应量明显超过噪声次序统计量（A ≳ 1.4）
> 时，argmax 才稳定落在缺陷带上，选带才开始划算。

## 1. 立论：把一个检测器拆成四重归约

这是全文的骨架，必须先立住，否则后面四组实验看起来像四件互不相关的事。

任何一个检测器（无论学习与否）都可写成四个归约的复合：

```
原始多通道波形 ──S──> 通道得分 ──F──> 频带得分 ──T──> 过车得分 ──Q──> 判决
                  空间归约        频率归约        时间归约        样本归约
```

- **S 空间归约**：96 个通道如何合成一个判断（取最大 / 取前 k 均值 / 空间邻域归一化）
- **F 频率归约**：多个频带的证据如何合成（**取平均** / **取最大（选带）** / 学习加权）
- **T 时间归约**：一条过车内多个窗、多个时刻如何合成（逐窗判决 / 沿时间池化）
- **Q 样本归约**：阈值取自分位数，分位数取自有限标定样本

四组实验正好各打一个轴，"选带失败"和"阈值不稳"在结构上是同一类错误：
**在样本量不足或效应量不足的轴上做了 argmax。**

### 1.1 核心判据：选带不增加信号，只增加方差

**这一步是实测的，不是推的。** 在同一条过车、同一套标定上，把两种频率归约的
过车分数摊开看（抖动 0.7，seed_0，48 条过车、29 条缺陷）：

| 归约方式 | AUC | d′ | 过车分数 sd | 均值差 Δ |
|---|---:|---:|---:|---:|
| **跨带取平均** | **0.704** | **0.87** | **0.10** | 0.08 |
| 跨带取最大 | 0.632 | 0.46 | 0.19 | 0.08 |
| 逐过车选带（零分布校正） | 0.666 | 0.19 | 0.61 | 0.12 |
| 逐过车选带（用标签作弊） | 0.657 | 0.41 | 0.57 | **0.22** |

读法很清楚：

- 平均与取最大的**均值差完全相同（0.08）**，但取最大的 sd 是两倍（0.19 对 0.10）。
  信号一点没多，方差多了一倍。
- 作弊版把均值差推到 0.22（说明选对带确实能提高信号），
  但 sd 涨到 0.57，d′ 仍只有 0.41，照样输给平均。
- 所以 AUC 的分母被选带的方差吃掉了：d′ = Δ / sd。

**结论：选带不是没选准，而是每选一次就引入一次随机尺度。**
一条过车里哪个带最大，由缺陷能量与该带本底噪声的相对位置决定；这个位置在过车之间变化，
于是过车分数被乘上一个随机的标尺，排序被打乱。

### 1.2 理想化模型：什么时候选带才开始划算

把上面这段实测放进一个可解析的模型，用来给出边界（**这是模型，不是结论**）。

设逐带标定后 z_b = μ_b + ε_b，ε_b ~ N(0,1)，缺陷在 M 个带中的 K 个上抬升 A：

- **平均**：T = (1/M)Σz_b，Δ_mean = K·A/M，sd = 1/√M → d′_mean = K·A/√M
- **取最大**：T = max_b z_b。A 小时 argmax 常落在**噪声带**，此时
  Δ ≈ A·(K/M) 而 sd ≈ v_M = sd(max of M normals) ≈ 0.6（M=5）；
  A 大到 argmax 稳定落在缺陷带上时，sd 回落到 ≈1，Δ ≈ A

蒙特卡洛（4×10⁵ 次，M=5/K=2 与 M=13/K=3）：

| A（单带 z 抬升） | M=5 取最大 | M=5 平均 | 胜者 |
|---:|---:|---:|---|
| 0.2 | 0.13 | **0.18** | 平均 |
| 0.5 | 0.36 | **0.45** | 平均 |
| 1.0 | 0.83 | **0.90** | 平均 |
| 1.2 | 1.03 | **1.07** | 平均 |
| 1.5 | **1.37** | 1.34 | 取最大 |
| 3.0 | **3.21** | 2.68 | 取最大 |

**模型给出的判据**：交叉点在 A ≈ 1.4，量级上等于噪声次序统计量的期望
m_M = E[max of M normals]（m_5 = 1.16，m_13 = 1.67）。

> 只有当单带效应量**明显超过噪声的最大值时**，argmax 才会稳定落在缺陷带上，
> 选带才开始划算；在此之前，取最大只是把噪声当成了信号。

⚠️ **模型的三个假设必须写进正文**，否则会被当成过度声称：

1. 各带独立同分布（真实 DAS 中相邻带有相关性，等效 M 会变小）；
2. 忽略逐窗 top-k 通道聚合（实测里那一层还会再引入一层选择）；
3. A 在缺陷带之间相同（真实缺陷的三个载波幅度不同）。

**因此 §5 的实验 D 不是验证模型，而是检验判据的方向**：它若在 A 跨过 ~1.4 时
出现交叉，判据可用；若交叉位置差很多，就如实给出经验修正项。

### 1.3 与已有文献的关系（判据的定位）

| 文献路线 | 在本判据下的位置 |
|---|---|
| 匹配滤波 / 固定带通 | `F` 取平均，`T` 池化，`Q` 无关 → 小 A 区间的近最优解 |
| 谱峭度 / kurtogram | `F` 取 argmax → 只在 A 大、K 小的区间有效 |
| 滤波器组 + 逐带标定 | `F` 取平均，`S` 取前 k → 稳健基线 |
| STAE / 掩蔽 AE / CVAE | `S`、`F`、`T` 全部学习 → 在 K、A 上都自适应，但需要足够样本 |
| 本文 | 给出 `F` 该选还是该平均的判据，并给出 `Q` 的样本量要求 |

## 2. 证据链（四组，已完成）

### E1｜频率归约：平均 vs 选择

**声称**：在本文的效应量区间，跨带平均严格优于选带，连用标签作弊都不行。

| 变体 | 抖动 0.0 | 抖动 0.4 | 抖动 0.7 |
|---|---:|---:|---:|
| **跨带取平均** | **0.714** | **0.717** | **0.695** |
| 跨带取最大 | 0.528 | 0.599 | 0.619 |
| 逐过车选带（零分布校正） | 0.414 | 0.549 | 0.541 |
| 逐 (过车, 通道) 选带 | 0.502 | 0.564 | 0.585 |
| **逐过车选带（用标签作弊）** | 0.484 | 0.575 | 0.581 |

- 口径校验：`bands_mean` 在抖动 0.7 得 0.695 ± 0.008，复现 `evaluate.py` 存下的 0.6931
- 关键点：**oracle 也输 0.11–0.23**，说明失败原因是"选"这个动作在丢信息，不是选得不准
- 陷阱：**裸选带掉到 0.261–0.370**（选择偏置让两类过车分数同时上移）
- 证据：报告 §7.1、§7.2、§7.3、§7.7；`outputs/pass_band.json`

### E2｜时间归约：逐窗 vs 逐过车

**声称**：缺陷带在一条过车之内恒定、在过车之间漂移，因此归约必须发生在过车尺度。

- 逐窗选带（谱峭度 0.575 / 最响带 0.543）显著劣于固定带通（0.882）
- 把归约提到过车尺度后仍然劣于平均（E1），说明**时间尺度不是唯一变量**
- 证据：报告 §7.1–§7.3、§7.7

### E3｜空间与表示：学习谱 vs 匹配滤波

**声称**：学习表示的唯一优势区间是"窄带稳态 + 过车间漂移"。

| 条件 | `stft_ae − 带通`（过车级 profile） | 种子一致 |
|---|---:|---:|
| 族内 抖动 0.0 | −0.030（打平） | — |
| **族内 抖动 0.7** | **+0.088** | **5/5** |
| 族外 `click` | +0.023（都在随机线） | 2/3 |
| 族外 `chirp` | −0.091 | 1/3 |
| 族外 `impulse_train` | **−0.188** | **0/3** |
| 族外 `am_resonance` | −0.081 | 0/3 |

- 补充否证：包络谱（`envspec`）、时频轨迹（`tftraj`）在它们最该赢的格子上只有 0.44–0.55，
  且系统性**低于随机**——注入缺陷抬高了包络均值，反而摊平了车轴调制
- 证据：报告 §4、§6、§7.4、§7.5、§7.6

### E4｜样本归约：共形分位数需要多少样本

**声称**：阈值稳定性是工程瓶颈，且它同样是"在小样本上做 argmax"的错误。

- n=21、α=0.05 时 `k = ceil((n+1)(1−α)) = 21`，即共形分位数**就是样本最大值**
- 实测永不报警的概率 0.31–0.38
- 标定样本从 21 增到 300：过车级召回散布 ±0.104 → ±0.014（带通）、±0.092 → ±0.014（STFT AE）
- 均值 FAR 始终在目标附近（0.040–0.051），**不稳定的是散布，不是偏差**
- 判据：`n_cal ≈ 5/α`；`1/α − 1 = 19` 是**有效性下限**，不是可用性下限
- 证据：报告 §3；`outputs/calibration_size_curve.json`

**四条证据的统一读法**（这是全文的收口，必须写进结论章）：

| 轴 | 错误做法 | 本文证据 |
|---|---|---|
| 频率 | 在 5–13 个带上取 argmax | E1：oracle 也输 |
| 时间 | 在 128 ms 窗内取 argmax | E2：逐窗选带全线落后 |
| 表示 | 假设"学的一定更好" | E3：只在窄带稳态成立 |
| 样本 | 在 21 个样本上取分位数 | E4：1/3 概率永不报警 |

**共性：在自由度不足的轴上做 argmax，都会把噪声当成信号。**

## 6. 【待补】实验 D：判据方向的检验

**为什么必须做**：前四组证据都是"某方法失败"。判据若只用来解释失败，仍是事后叙事。
只有它**预测**一个尚未观测到的现象并被验证，才成为理论。这是把本文从"负结果集合"
升级为"判据"的唯一一步。

**设计（已按 §1.2 的判据修正）**：

- 形态固定 impact（K≈2–3），扫 SNR：−5, 0, 5, 10, 15, 20 dB，每点 5 种子
- 每点比较 ilterbank（平均）与 andselect（选择），记录两条 AUC
- **关键：每点同时测 A**——用 oracle 带上的 z 均值减去正常过车同带均值，
  把每个 SNR 点放回 §1.2 的横轴
- 判据预测：A 跨过 ≈1.4 时两条曲线交叉

**判读**：

| 观测 | 结论 |
|---|---|
| 交叉出现在 A≈1.0–2.0 | 判据可用，作为本文的理论产物写进第 4 章 |
| 交叉出现但位置偏离 | 判据方向对、常数需标定，给出经验修正 |
| 完全不交叉 | 判据被证伪，退回纯经验结论，如实写 |

**成本**：6 个 SNR × 5 种子 × 2 模型 ≈ 半天（andselect 已实现）。

**已知风险**：

1. **饱和**：+20 dB 时所有方法 AUC→1，看不到交叉。缓解：以实测 A 为准，
   只保留 A 落在 0.3–3 之间的点，必要时加密采样。
2. **A 随着 SNR 不是线性增长**：注入 SNR 是预处理后的局部 SNR，与逐带 z 抬升 A
   之间隔着带通与标定，必须实测而非假设。
3. 若交叉始终不出现，也有价值：说明在本任务里"选带"连强效应都救不回来，
   这本身就是比现在更强的负结果。

## 7. 答辩可能被问的问题

| 问题 | 回答要点 |
|---|---|
| "你的模型在哪里？" | 本文贡献是判据不是模型；第 4 章给出选/平均的定量边界，第 5 章验证。若必须要模型，`stft_ae` 是唯一在特定区间有效的，且区间已被界定 |
| "仿真数据能说明什么？" | 能说明**方法之间的关系**，不能说明绝对性能。第 3 章的所有严格性（SNR 标定、种子、指标隔离）都是为了这个"关系"可信 |
| "为什么带通这么强，是不是任务太简单？" | 恰恰相反：带通强是因为缺陷是**弱而宽**的。若任务变简单（缺陷更强更窄），按判据选带会反超——实验 D 就是测这个 |
| "负结果有什么价值？" | 它排除了四条会被反复尝试的路线，并给出何时该用哪条的判据；对工程是省时间的，对学术是防重复的 |
| "和 STAE 那类工作怎么比？" | 他们在自己的数据与协议下报告高精度；本文指出其优势区间的边界，并给出可复现的对照协议 |
| "真实数据来了怎么办？" | 第一步是跨带平均匹配滤波基线（不是网络），再用 E1–E4 的四个轴逐一定标 |
